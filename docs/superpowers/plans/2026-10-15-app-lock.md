# App Lock Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans.

**Goal:** Opsiyonel PIN/biyometrik ile uygulama kilidi.

**Architecture:** `LockGate` wrapper in `App.tsx`; preferences in SQLite `app_settings`.

**Tech Stack:** expo-local-authentication, expo-crypto.

## Global Constraints

- PIN stored hashed only; user can disable lock from Settings.

---

### Task 1: PIN hash utilities

**Files:**
- Create: `src/utils/pinStorage.ts`

**Interfaces:**
- Produces: `setPin(pin: string)`, `verifyPin(pin: string): boolean`, `isPinEnabled()`, `clearPin()`

- [ ] **Step 1:** `npx expo install expo-local-authentication expo-crypto`
- [ ] **Step 2:** Salt in app_settings; SHA256(salt+pin).

### Task 2: LockGate component

**Files:**
- Create: `src/components/LockGate.tsx`

- [ ] **Step 2:** AppState background → foreground re-lock if elapsed > 5 min and setting on.
